Open-source tools for single-cell biology

Guides, API references, and source code for the analysis and annotation software we build at Nygen Analytics.

  • CyteArc

    Python

    Out-of-core analysis for single-cell RNA, ATAC, protein, and multi-omic data. Scales to 100M+ cells, and every result traces back to the cells and parameters behind it.

    pip install cytearc
    Documentation → GitHub PyPI

  • CyteBase

    Python

    A searchable catalog of public single-cell datasets, published as CyteArc DataStores on Hugging Face. Search by tissue, disease, or cell type, then open or mount a dataset without downloading it.

    pip install cytebase
    Documentation → GitHub PyPI

  • CyteType

    Python

    Evidence-backed cell type annotation for Scanpy and AnnData. Each cluster gets a cell type, a Cell Ontology ID, a confidence score, and an interactive report.

    pip install cytetype
    Documentation → GitHub Paper

  • CyteTypeR

    R

    The CyteType annotation workflow for Seurat objects, with the same evidence and reports.

    devtools::install_github("NygenAnalytics/CyteTypeR")
    Get started → GitHub

  • CyteOnto

    Hosted API

    Semantic comparison of cell type labels in Cell Ontology space, for benchmarking annotation methods beyond exact string matches. No API key needed.

    https://cyteonto.nygen.io/compare
    Read the guide → GitHub
